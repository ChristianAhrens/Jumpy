Detailed Description

juce::PopupMenu::CustomComponent wrapper that sizes an arbitrary component to 75 % of the shorter screen dimension, bounded by a configurable minimum.

Used to embed AboutComponent inside the about popup menu with a size that scales sensibly across all supported screen sizes.
