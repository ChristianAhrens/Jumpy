Detailed Description

All persistent properties associated with a single trigger button slot.

A TriggerDetails bundle carries everything needed to configure one button: a display name, a background colour, the target timecode jumped to on activation, and two optional external trigger sources (an OSC address pattern and a MIDI command assignment).

Serialisation uses a semicolon-delimited string:

name;colourHex;hh:mm:ss:ff;/osc/address;midiHex

This string is stored verbatim as text content inside a <TRIGGERDETAILS> XML element in the configuration file.
