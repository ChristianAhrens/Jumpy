Detailed Description

Desktop document window that hosts MainComponent and mirrors the OS dark-mode setting.

On construction the window creates a Jumpy::MainComponent, wires up the palette-style change callback so that user-selected themes propagate to the global juce::LookAndFeel, and registers itself as a juce::DarkModeSettingListener so the OS dark/light preference is followed automatically whenever m_followLocalStyle is true.

Platform behaviour:

  • iOS / Android: runs full-screen with the screen saver disabled.
  • Linux: enters kiosk mode.
  • macOS / Windows: resizable window, centred at its preferred size.
